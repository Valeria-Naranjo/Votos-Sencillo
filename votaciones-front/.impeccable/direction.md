# Access control direction contract

- FORM seed key: `institutional-access-ledger`
- Corroboration: the user-supplied GP-CENTER role matrix establishes grouped modules, screen-level actions and fast bulk assignment; the existing Votaciones shell establishes the guinda institutional visual language.
- World: a calm municipal operations ledger—dense enough for administrators, explicit about security consequences, and optimized for repeated permission work.
- Type: retain the product's compact sans-serif hierarchy; strong page/module labels, quiet explanatory copy.
- Material: flat operational surfaces, restrained borders, warm neutral ground and guinda state accents; no decorative illustration.
- Ground: existing warm off-white application background, preserving the established shell.
- Density: desktop matrix with a persistent role rail; compact mobile role strip with the active role first in DOM and visual order.
- Signature interaction: one-screen role selection, grouped grant/revoke controls and explicit save state; user-role reassignment confirms automatic session revocation.
- Guardrails: no frontend-only authorization, no hidden immediate role mutation, no permission grant without view, no undeclared custom actions, and no non-SuperAdmin escalation to SuperAdmin.
